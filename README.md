# Physics Ball Balance Game

A beginner-friendly physics-based obstacle game developed using Unity.

## 🎮 Game Overview

In this game, the player controls a physics-driven ball and must carefully navigate through obstacles, narrow paths, and moving challenges to reach the goal platform without falling off the map.

The game focuses on realistic physics interactions such as gravity, collisions, momentum, and force-based movement.

---

## 🛠 Engine Used

- Unity 3D

---

## ⚙ Physics Features Implemented

- Rigidbody-based player movement
- Gravity system
- Force-based controls using `AddForce()`
- Collision detection
- Moving physics obstacles
- Rotating obstacles
- Trigger-based interactions
- Falling/restart system
- Physics-based momentum and sliding

---

## 🎯 Gameplay Features

- Physics-controlled ball movement
- Moving and rotating obstacles
- Narrow balancing platforms
- Coin collection system
- Score tracking UI
- Win and Game Over screens
- Restart functionality

---

## 🎮 Controls

| Key | Action |
|------|--------|
| W / Up Arrow | Move Forward |
| S / Down Arrow | Move Backward |
| A / Left Arrow | Move Left |
| D / Right Arrow | Move Right |
| R | Restart Game |

## 🚀 How to Play

1. Start the game
2. Control the ball using keyboard keys
3. Avoid obstacles and falling off platforms
4. Collect coins to increase score
5. Reach the yellow goal cube to win

---


## 🔁 Restart Condition

- Falling into the Death Zone results in Game Over
- Press `R` to restart the level
